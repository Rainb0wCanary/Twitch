# Drops — Auto Collector

> **v1.4.0** — Автоматический сбор наград Drops с Twitch и Kick

Расширение Chrome (Manifest V3) для полностью автоматизированного фарма дропов.  
Поддерживает Twitch и Kick, умную систему приоритетов, синхронизацию с инвентарём и красивый современный интерфейс.

---

## Возможности

| Функция | Описание |
|---|---|
| 🤖 **Автопросмотр** | Последовательно открывает каналы, проверяет наличие категории и ведёт счёт времени |
| 📥 **Импорт с Facepunch** | Автоматически подгружает актуальных стримеров и их дропы с `twitch.facepunch.com` и `kick.facepunch.com` |
| 🔄 **Синхронизация инвентаря** | Сверяет прогресс с реальным инвентарём на `twitch.tv/drops/inventory` |
| 🎬 **Видео-превью наград** | Показывает 3D-анимацию предмета прямо в попапе и на странице статистики |
| ⚡ **Умные приоритеты** | Автосортировка: незавершённые (по % прогресса) → не начатые → завершённые в самом низу |
| ⏱️ **Точный таймер** | Отсчёт времени в реальном времени (каждую секунду) |
| 📊 **Страница статистики** | Детальный дашборд со сводкой, карточками дропов и журналом логов |
| 🚫 **ЧС каналов** | Временная и постоянная блокировка на уровне канала и всей группы |

## Интерфейс

### Попап расширения
- **LIVE-индикатор** и статус бота (В эфире / Остановлено)
- **Карточка текущего стрима** с видео-анимацией фармимого дропа, обратным таймером и мини-прогрессбаром
- **Управление**: кнопки ⏮ Предыдущий, ▶ Старт / ⏹ Стоп, ⏭ Следующий
- Быстрый переход в **Панель дропов →**

### Страница статистики (`stats.html`)
- **Сводная панель**: Всего дропов / В прогрессе / Завершено / Накопленное время
- **Карточки групп дропов** с видео/картинкой награды, прогрессбаром, временем просмотра, приоритетом и управлением
- **Выдвижная панель настроек** (⚙️ Настройки): параметры бота + кнопки импорта кампаний Facepunch (Twitch/Kick) + создание групп
- **Системный журнал логов** (сворачиваемый)

## Быстрый старт

1. **Установите расширение** через `chrome://extensions` → *Загрузить распакованное* → выберите папку проекта.

2. **Импортируйте кампанию** — откройте страницу статистики → ⚙️ Настройки → «📥 Twitch» или «📥 Kick».  
   Расширение само подтянет актуальных стримеров и цели просмотра с Facepunch.

3. **Сверьте с инвентарём** — нажмите «🔄 Инвентарь» в шапке, чтобы синхронизировать прогресс с реальным инвентарём дропов.

4. **Нажмите ▶ Старт** в попапе — бот начнёт автопросмотр.

## Конфигурация

### Параметры бота (панель ⚙️ Настройки)

| Параметр | Описание |
|---|---|
| `URL категории поиска` | URL категории игры, например `https://www.twitch.tv/directory/category/rust` |
| `Интервал проверки (мин)` | Как часто проверять стрим на наличие нужной категории |
| `Ожидание перед проверкой (сек)` | Задержка после открытия вкладки перед первой проверкой |
| `Макс. попыток` | Сколько раз пробовать найти ссылку перед временным баном |
| `Временный бан (H.MM.SS)` | Время блокировки канала при неудаче (например, `0.05.00` = 5 минут) |

### Формат конфига (`config.json`)

```json
{
  "searchUrlPart": "https://www.twitch.tv/directory/category/rust",
  "checkIntervalMinutes": 1,
  "waitBeforeCheck": 20,
  "maxAttempts": 5,
  "tempBlacklistSeconds": "0.05.00",
  "channels": [
    {
      "url": "https://www.twitch.tv/streamer1",
      "watchTime": "2.00.00",
      "dropId": "drop_furnace"
    },
    {
      "url": "https://www.twitch.tv/streamer2",
      "watchTime": "2.00.00",
      "dropId": "drop_furnace"
    },
    {
      "url": "https://www.twitch.tv/streamer3",
      "watchTime": "1.00.00",
      "dropId": "drop_backpack"
    }
  ]
}
```

> **Группы дропов**: Если несколько каналов имеют одинаковый `dropId`, время просмотра суммируется между ними. Как только суммарное время достигает `watchTime` — вся группа уходит в ЧС.

## Система приоритетов

Бот всегда выбирает следующий канал по порядку приоритета:

1. **Частично просмотренные** (прогресс от 1% до 99%) — сортируются по убыванию %: 80% → 77% → и т.д.
2. **Не начатые** (0%) — идут после частично просмотренных
3. **Завершённые** (100%) — в самом низу

> ⚠️ **Важно**: Бот **не прерывает** текущий просмотр при разблокировке высокоприоритетного канала. Переключение произойдёт только при естественном завершении текущего дропа, уходе стримера в оффлайн или смене категории.

## Часто задаваемые вопросы

**Q: Стример ушёл в оффлайн — что происходит?**  
A: Канал отправляется во временный ЧС, бот автоматически переходит на следующий.

**Q: Можно смешивать Twitch и Kick каналы?**  
A: Да, в одном конфиге могут быть оба типа.

**Q: Сбрасывается ли время при перезапуске расширения?**  
A: Нет, всё время хранится в `chrome.storage.local` и переживает перезапуски.

**Q: Как отслеживать прогресс?**  
A: Откройте страницу статистики — там видны проценты выполнения, время просмотра и статус каждого канала в режиме реального времени.

## Советы по отладке

- **Попап**: правый клик → Inspect Popup → Console
- **Background**: `chrome://extensions` → «Service Worker» → Console  
- **Storage**: `chrome.storage.local.get(null, console.log)` в консоли background

## Файловая структура

```
├── manifest.json       # Манифест расширения (MV3)
├── background.js       # Service Worker: логика автопросмотра

├── styles.css          # Единая дизайн-система (тёмная тема)
├── icons/              # Иконки расширения (16/32/48/128 px)
└── config.json         # Пример конфигурации
```
