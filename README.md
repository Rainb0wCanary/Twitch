# Drops — Auto Collector

> **v1.5.1** — Универсальный автоматический сбор наград Drops с Twitch и Kick

Расширение Chrome (Manifest V3) для полностью автоматизированного фарма дропов для **любой игры и категории Twitch**.  
Поддерживает парсинг активных кампаний с Twitch, интеллектуальное раскрытие аккордеонов, автоизвлечение времени просмотра и каналов стримеров, таймеры обратного отсчёта окончания кампаний, глубокую сверку с инвентарём и умные приоритеты.

---

## Возможности

| Функция | Описание |
|---|---|
| 🎯 **Универсальные кампании Twitch** | Считывает все активные кампании с `twitch.tv/drops/campaigns`. Подходит для **Rust, GTA V, CONTROL, Apex Legends, CS2, Warframe и любой другой игры**! |
| 🔍 **Мгновенный поиск игр** | Умный поиск и автокомплит по названию игры и кампании прямо в модальном окне |
| ⏳ **Таймер окончания кампании** | Живой обратный отсчёт времени до конца кампании (`Осталось: X дн. Y ч.`) в шапке статистики и в попапе |
| ⏱️ **Точный парсинг времени наград** | Распознаёт точное требуемое время просмотра для каждой карточки дропа (например, «1 час», «60 минут», «120 минут») |
| 🌐 **Прямой сбор с Twitch** | Загрузка активных кампаний напрямую со страницы `twitch.tv/drops/campaigns` через фоновую вкладку в один клик |
| 🤖 **Автопросмотр** | Последовательно открывает каналы, проверяет наличие категории и ведёт точный счёт времени просмотра |
| 📥 **Импорт Facepunch (Rust)** | Сохранена обратная совместимость с `twitch.facepunch.com` и `kick.facepunch.com` |
| 🔄 **Умная синхронизация инвентаря** | Автоматически нажимает «Загрузить еще» для старых порций наград (2-я, 3-я двадцатки), считывает карточки даже без загруженных картинок (по тексту и датам «позавчера», «вчера») и сопоставляет предметы на 100% |
| 🎬 **Видео и фото превью** | Отображает превью предметов и обложки игр прямо в интерфейсе |
| ⚡ **Умные приоритеты** | Автосортировка: незавершённые (по % прогресса) → не начатые → завершённые в самом низу |
| 🚫 **ЧС каналов** | Временная и постоянная блокировка на уровне канала и всей группы |

## Интерфейс

### Попап расширения (`popup.html`)
- **Индикатор активной кампании**: название выбранной игры, таймер окончания кампании (`⏳ Осталось: X дн. Y ч.`) и быстрая ссылка на хаб
- **LIVE-индикатор** и статус бота (В эфире / Остановлено)
- **Карточка текущего стрима** с анимацией/картинкой награды, обратным таймером и прогрессбаром
- **Управление**: кнопки ⏮ Предыдущий, ▶ Старт / ⏹ Стоп, ⏭ Следующий
- Быстрый переход в **Панель дропов →**

### Страница статистики и управления (`stats.html`)
- **Баннер активной кампании**: обложка игры, название, оставшееся время (`⏳ Осталось: ...`), даты проведения и прямая ссылка на категорию Twitch
- **Каталог кампаний Twitch Drops (модальное окно)**:
  - Мгновенный поиск игр по названию
  - Кнопка «🌐 Считать с Twitch» для обновления списка активных кампаний со страницы `twitch.tv/drops/campaigns`
  - Сетка карточек кампаний с обложками, сроками и кнопкой выбора «📥 Выбрать»
  - Автоматическое предложение найти активных стримеров в категории при выборе кампаний с общими дропами
- **Сводная панель**: Всего дропов / В прогрессе / Завершено / Накопленное время
- **Карточки групп дропов** с визуалом награды, прогрессбаром, временем просмотра, приоритетом и управлением
- **Выдвижная панель настроек** (⚙️ Настройки): параметры бота, кнопки Facepunch (Twitch/Kick), добавление каналов вручную
- **Системный журнал логов** (сворачиваемый)

## Быстрый старт

1. **Установите расширение** через `chrome://extensions` → включите *Режим разработчика* → *Загрузить распакованное* → выберите папку проекта.

2. **Выберите кампанию Drops**:
   - Нажмите кнопку **«🎯 Кампании Drops»** в шапке или в баннере активной кампании.
   - Введите название вашей игры в строку поиска (например, `Rust`, `Control`, `GTA`, `Apex`).
   - Нажмите **«📥 Выбрать»** на нужной карточке — расширение автоматически сформирует конфиг, группы дропов, стримеров и таймеры!
   - *(При необходимости можно нажать «🌐 Считать с Twitch» для принудительного обновления списка).*

3. **Сверьте с инвентарём** — нажмите «🔄 Инвентарь» в шапке, чтобы подтянуть уже полученный прогресс с Twitch.

4. **Нажмите ▶ Старт** в попапе — бот автоматически начнёт фарм дропов.

## Конфигурация

### Параметры бота (панель ⚙️ Настройки)

| Параметр | Описание |
|---|---|
| `URL категории поиска` | URL категории игры, например `https://www.twitch.tv/directory/category/rust` |
| `Интервал проверки (мин)` | Как часто проверять стрим на наличие нужной категории |
| `Ожидание перед проверкой (сек)` | Задержка после открытия вкладки перед первой проверкой |
| `Макс. попыток` | Сколько раз пробовать найти ссылку перед временным баном |
| `Временный бан (H.MM.SS)` | Время блокировки канала при неудаче (например, `0.05.00` = 5 минут) |

### Формат конфига (`config.json`)

```json
{
  "searchUrlPart": "https://www.twitch.tv/directory/category/rust",
  "checkIntervalMinutes": 1,
  "waitBeforeCheck": 20,
  "maxAttempts": 5,
  "tempBlacklistSeconds": "0.05.00",
  "channels": [
    {
      "url": "https://www.twitch.tv/streamer1",
      "watchTime": "2.00.00",
      "dropId": "drop_furnace"
    },
    {
      "url": "https://www.twitch.tv/streamer2",
      "watchTime": "2.00.00",
      "dropId": "drop_furnace"
    },
    {
      "url": "https://www.twitch.tv/streamer3",
      "watchTime": "1.00.00",
      "dropId": "drop_backpack"
    }
  ]
}
```

> **Группы дропов**: Если несколько каналов имеют одинаковый `dropId`, время просмотра суммируется между ними. Как только суммарное время достигает `watchTime` — вся группа уходит в ЧС.

## Система приоритетов

Бот всегда выбирает следующий канал по порядку приоритета:

1. **Частично просмотренные** (прогресс от 1% до 99%) — сортируются по убыванию %: 80% → 77% → и т.д.
2. **Не начатые** (0%) — идут после частично просмотренных
3. **Завершённые** (100%) — в самом низу

> ⚠️ **Важно**: Бот **не прерывает** текущий просмотр при разблокировке высокоприоритетного канала. Переключение произойдёт только при естественном завершении текущего дропа, уходе стримера в оффлайн или смене категории.

## Часто задаваемые вопросы

**Q: Стример ушёл в оффлайн — что происходит?**  
A: Канал отправляется во временный ЧС, бот автоматически переходит на следующий.

**Q: Можно смешивать Twitch и Kick каналы?**  
A: Да, в одном конфиге могут быть оба типа.

**Q: Сбрасывается ли время при перезапуске расширения?**  
A: Нет, всё время хранится в `chrome.storage.local` и переживает перезапуски.

**Q: Как отслеживать прогресс?**  
A: Откройте страницу статистики — там видны проценты выполнения, время просмотра и статус каждого канала в режиме реального времени.

